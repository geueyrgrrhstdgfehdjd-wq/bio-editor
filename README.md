# Bio Site

เว็บ Bio สวยๆ 3D พร้อมหลังบ้านให้ทุกคนตั้งค่าเอง

## คุณสมบัติ
- หน้า Bio สาธารณะ พร้อมกรอบโลโก้แบบปรับได้ (วงกลม, เหลี่ยมมน, หกเหลี่ยม, ไม่มีกรอบ)
- ระบบสมัครสมาชิก / เข้าสู่ระบบ / Autologin 7 วัน
- หลังบ้านจัดการ Bio ครบ: ชื่อ, คำอธิบาย, สี, ลิงก์, ข้อความ
- ตั้งค่ากรอบโลโก้ผ่านหน้าเว็บ (ขยับ X/Y, ปรับขนาด)
- เอฟเฟกต์ 3D Tilt, Particle Background, Font Awesome Icons
- รองรับ Dark/Light mode
- Responsive

## การใช้งาน
- หน้าแรก: `http://localhost:3000`
- สมัครสมาชิก: `/auth/register`
- เข้าสู่ระบบ: `/auth/login`
- หลังบ้าน: `/dashboard`
- ดู Bio: `/:username`
